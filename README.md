# tldlist-data

`tlds.json` is the extension list used by the TLD List app: the IANA root zone (type, manager) merged with meanings, registries and typical prices from tldlist.us (CC BY, attribution: https://tldlist.us/). Rebuilt weekly by `.github/workflows/refresh.yml` with `build_tlds.py` (sends a descriptive User-Agent, polite request spacing).

Served at https://cinderspire.github.io/tldlist-data/tlds.json (GitHub Pages, main branch, root).
